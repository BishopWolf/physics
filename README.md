# physics — a Lean 4 formalisation of gravitation

A component (coordinate) formalisation of general relativity — maintained in
[Physlib](https://github.com/leanprover-community/physlib) on its `gravity`
branch — together with a Vulkan compute path that verifies the solutions
numerically.

The development itself lives in Physlib on its `gravity` branch, which is not
yet merged upstream. Until it is, the branch's unmerged modules are **vendored**
here (`gravitation/vendor/Gravitation/Relativity/General/`, from commit
`41abde06`, as the module path `Gravitation.Relativity.General.*`) and the base
library is a pinned Physlib **master**. The namespace is still
`GeneralRelativity` and the proofs are unchanged, so removing the vendored copy
and switching the imports back to `PhyslibAlpha.Relativity.General.*` is the
whole migration. The repository adds what Physlib does not carry: the numerical
cross-check, the axiom/proof-status tooling, and the written account.

Curvature *definitions* exist in several projects; this development adds
solution theory — kernel-checked statements that specific metrics have specific
curvature and solve specific field equations — and the standard alternatives to
general relativity. See [`STATUS.md`](STATUS.md) for the survey that motivates
the scope.

## The Physlib dependency and the vendored branch

The general-relativity development (`PhyslibAlpha/Relativity/General/`, 38 Lean
modules, namespace `GeneralRelativity`) is on Physlib's `gravity` branch, which
is not yet merged upstream. The build therefore has two parts:

| Source | What | Revision |
| --- | --- | --- |
| `physlib` git requirement | base library: units, cosmology, Mathlib | upstream master `cbd02238` |
| `gravitation/vendor/` | the 37 unmerged GR modules, proofs unchanged | branch `gravity` `41abde06` |

`Schwarzschild/IncompressibleSphere.lean` is already on master, so it is not
vendored and comes from the dependency. The vendored files keep their proofs and
their `GeneralRelativity` namespace but take the `Gravitation.Relativity.General.*`
module path, so they cannot collide with Physlib's own `PhyslibAlpha.*` library
globs. The `physlib` requirement is a merged upstream commit — the merge base the
branch was written against — so nothing in the build depends on a personal fork
or a moving branch.

**Removal once the branch is merged:** delete `gravitation/vendor/`, remove the
`GravitationVendor` library from `gravitation/lakefile.toml`, switch the
umbrella imports from `Gravitation.Relativity.General.*` back to
`PhyslibAlpha.Relativity.General.*`, point `physlib` at the merged revision, then
run `lake update physlib`, `lake build`, `scripts/audit_axioms.sh` and
`scripts/proof_status.sh`. `gravitation/vendor/README.md` records the
provenance and the exact steps.

CI guards the copy: `scripts/check_vendor_sync.sh` fetches the `gravity` branch,
fails if its tip no longer matches `vendor/REVISION`, and diffs every vendored
module against the branch after applying the same import rewrite. A branch move
therefore cannot leave the vendored proofs silently stale.

`lake build` compiles the vendored modules and the Physlib modules the umbrella
imports, so the first build takes a few minutes; subsequent builds are
incremental.

## What is proved

All results are checked by the Lean kernel against Mathlib `v4.36.0`, with no
`sorry` and no added axioms. The solution theory lives in the vendored `gravity`
tree or the pinned upstream dependency; the one-dimensional wave theorem is
local. The audit covers 732 declarations, 493 of them theorem-like.

### Curvature calculus and the field equations

| Result | Statement |
| --- | --- |
| `GeneralRelativity.eta4_mul_self` | `η * η = 1`, i.e. `η` is its own inverse |
| `GeneralRelativity.MetricTensor.ginv_symm` | the inverse of a symmetric metric is symmetric |
| `GeneralRelativity.Riemann.skew_first` | `R_{ijkl} = −R_{jikl}`, derived from pair symmetry and antisymmetry in the last pair |
| `GeneralRelativity.ricci_symm` | `Ric_{ij} = Ric_{ji}`, derived from pair symmetry |
| `GeneralRelativity.einstein_symm` | the Einstein tensor is symmetric |
| `GeneralRelativity.sum_ginv_mul_g` | `∑ g^{ij} g_{ij} = n` |
| `GeneralRelativity.metricTrace_einstein` | `g^{ij}G_{ij} = (1 − n/2) S`; in 4D the trace of `G` is `−S` |
| `GeneralRelativity.vacuum_iff_ricci_flat` | in 4D, `G = 0 ↔ Ric = 0` |
| `GeneralRelativity.SchwarzschildDeSitter.sds_frame_bianchi` | the contracted Bianchi identity is proved, not assumed, for the frame Einstein space (`Ric = Λη`, `S = 4Λ`), and `sds_frame_einstein_conserved` gives `∇·G = 0` |
| `GeneralRelativity.Schwarzschild.kretschmann_scalar_total`, `GeneralRelativity.SchwarzschildDeSitter.kretschmann_sds_total` | the frame Kretschmann scalars with no hypotheses: the `r ≠ 0` of `kretschmann_scalar` / `kretschmann_sds` is removed |
| `GeneralRelativity.Pipeline.christoffel`, `riemann`, `ricciOf`, `scalarOf`, `einsteinOf` | the chain `g ↦ ∂g ↦ Γ ↦ ∂Γ ↦ R ↦ Ric ↦ S ↦ G` from metric components |

The Riemann tensor carries antisymmetry in the last pair, pair symmetry
`R_{ijkl} = R_{klij}`, and the first Bianchi identity; antisymmetry in the first
pair is *proved* from those (`skew_first`), not assumed.

### Exact solutions

| Solution | Result |
| --- | --- |
| Minkowski | `Minkowski.minkowski_ricci_eq_zero`, `minkowski_einstein_eq_zero`: computed flatness and vacuum |
| Schwarzschild | `Schwarzschild.ricci_eq_zero`; `Schwarzschild.kretschmann_scalar` (`48M²/r⁶`); `Schwarzschild.weyl_purely_electric`; metric-level `Pipeline.ricciOf_schwarzschild`, `scalarOf_schwarzschild`, `einsteinOf_schwarzschild` |
| Interior Schwarzschild | `Schwarzschild.IncompressibleSphere`: TOV pressure profile and the Buchdahl compactness bound |
| Schwarzschild–de Sitter | `SchwarzschildDeSitter.kretschmann_sds` (`48M²/r⁶ + 8Λ²/3`); `sdsRic_eq` (`Ric = Λη`), `sdsScalar_eq` (`S = 4Λ`), `sdsEinstein_eq` (`G = −Λη`); metric-level `Pipeline.ricciOf_sds`, `scalarOf_sds`, `einsteinOf_sds` for general `Λ` |
| Reissner–Nordström | `ReissnerNordstrom.einsteinOf_rn_eq_maxwell`: `G_{ij} = 8π T^{EM}_{ij}`; trace-free Maxwell stress-energy; Cauchy/event horizons and the extremal limit |
| Kerr | `Kerr.ricciOf_kerr_eq_zero`, `Kerr.scalarOf_kerr_eq_zero`, `Kerr.einsteinOf_kerr_eq_zero`: the Boyer–Lindquist metric is vacuum, with horizons, ergosphere and frame dragging |
| FLRW | `FLRW.ricciOf_flrw`, `scalarOf_flrw`, `einsteinOf_flrw`; `einsteinOf_flrw_iff_friedmann`: the Einstein equations hold exactly when the Friedmann equations do |

The static spherically symmetric family is also handled once, for an arbitrary
lapse profile, in `StaticSpherical` (`ricciOf_staticSpherical`,
`scalarOf_staticSpherical`, `einsteinOf_staticSpherical`), so Schwarzschild,
Schwarzschild–de Sitter and Reissner–Nordström share one derivation.

For Schwarzschild–de Sitter the metric-level derivation is closed end to end:
`christoffel_eq_sdsG` identifies the metric's Christoffel symbols with the
closed form, `pd_christoffel_eq_pd_sdsG` pushes the equality through coordinate
differentiation, `pd_sdsG_eq_sdsDGFull` evaluates all 256 derivative slots, and
`riemann_sds_components` gives all six independent Riemann components. The frame
Weyl electric part is proved to be `diag(0, −2M/r³, M/r³, M/r³)` for every `Λ`:
the cosmological constant enters the Riemann tensor only through the trace the
Weyl tensor removes.

### Cauchy problem, linearized gravity, and constants

| Result | Statement |
| --- | --- |
| `InitialValue` | ADM Hamiltonian and momentum constraints `H = ³R + (tr K)² − K_ij K^ij`, `M_i`; moment-of-time-symmetry and maximal-slicing reductions; a non-vacuum `K = diag(1,1,0)` example |
| `Geodesics.geodesic_ivp_exists` | local existence for `γ'' = −Γ(γ)(γ', γ')` from `(x₀, v₀)`, via Picard–Lindelöf |
| `Geodesics.geodesic_ivp_unique` | uniqueness under an explicit Lipschitz hypothesis |
| `GeneralRelativity.dAlembert_wave_equation` | the d'Alembert formula solves `∂ₜ²u = ∂ₓ²u` with prescribed initial position and velocity |
| `GeneralRelativity.waveEnergy_eq_initial` | energy conservation for a 1D wave field with homogeneous Dirichlet data |
| `GeneralRelativity.wave_zero_of_zero_data` | interior zero-data uniqueness for the 1D wave equation, by energy |
| `GeneralRelativity.wave_zero_of_zero_data_Icc` | zero-data uniqueness on the closed interval |
| `GeneralRelativity.wave_unique_of_same_data` | general-data uniqueness on the closed interval |
| `Linearized.linEinstein_lorenz_gauge` | in Lorenz gauge the linearized Einstein tensor is `−½ □ h̄` |
| `Linearized.ttWave_linEinstein_zero` | transverse–traceless gravitational waves solve the linearized vacuum equations |
| `Linearized.newtonianPerturb_poisson_iff` | the Newtonian limit is Poisson's equation `∇²Φ = 4πρ` |
| `GravitationalConstant` | dimension `L³ M⁻¹ T⁻²`, CODATA 2022 SI value, and natural units with `c = G = k_B = 1` |

The wave theorem is a linear one-dimensional model, not a field-equation
existence theorem. Development existence for the full field equations
(Choquet–Bruhat–Geroch) is neither claimed nor axiomatised; `InitialValue` is a
predicate on a slice.

### Modified and alternative theories

`GeneralRelativity.Modified` contains machine-checked developments of sixteen
theories usually discussed as replacements or extensions of general relativity,
from structural laws to field-equation reductions:

| Module | Content |
| --- | --- |
| `BransDicke`, `FRGravity` | PPN parameters, `ω → ∞` GR limit, coupling bounds, Starobinsky potential and mass, the `f(R)` trace equation |
| `ChameleonScreening` | density-dependent mass, shrinking Compton range, thin-shell suppression of the fifth force |
| `Galileon`, `Ostrogradsky` | total-derivative structure; degenerate Hessian and the ghost Hamiltonian |
| `MOND`, `MOG`, `TeVeS`, `Nordstrom` | deep-MOND flat rotation, bounded MOG enhancement, TeVeS disformal metric with explicit inverse, Nordström's `S = −6□φ/φ³` and Einstein–Fokker equivalence |
| `PPN` | Will–Nordtvedt `γ, β, …`, light deflection, Shapiro delay, perihelion precession, Nordtvedt parameter, Cassini bound |
| `EinsteinAether`, `MassiveGravity` | spin-2/1/0 mode speeds and GW170817 luminality; Fierz–Pauli mass terms, vDVZ ratios, dRGT potential |
| `KaluzaKlein` | 5D metric, Kaluza miracle `R⁵ = R⁴ − ¼F²`, 4D Einstein–Maxwell equations |
| `Lovelock`, `EinsteinCartan`, `Teleparallel` | Gauss–Bonnet variation vanishing for `n ≤ 4`; contorsion and spin-torsion; Weitzenböck torsion and `R = −T + B` for flat FLRW |

The depth varies by theory and is stated per module: Einstein–Cartan,
teleparallel, Kaluza–Klein, Lovelock, Einstein–Aether, massive gravity, PPN,
Brans–Dicke/f(R) and chameleon screening have their field equations or exact
reductions proved; MOND, MOG and TeVeS remain structural; the Galileon result is
one-dimensional. Empirical strengths and weaknesses are *not* theorems and are
not claimed as such. The full bibliography is [`docs/references.bib`](docs/references.bib), and
each Physlib module cites its sources under `iv. References`.

## Vulkan tensor pass

The shader takes any metric given as an analytic function of `(t, r, θ, φ)`,
differentiates it by central differences, and computes

`Γ^k_{ij}` → `∂Γ` → `R^ρ_{σμν}` → `Ric_{σν} = R^ρ_{σρν}` → `R = g^{μν}Ric_{μν}` →
`G_{μν} = Ric_{μν} − ½ R g_{μν}`,

writing 70 doubles per lattice point to an SSBO — the metric, Ricci, `R`, `G`,
the Kretschmann scalar, the electric part in the orthonormal frame and four
Riemann components. The inverse metric is a cofactor 4×4 inverse, so
non-diagonal metrics are handled; Kerr exercises that path.

Measured on an AMD RX 570 (RADV POLARIS10, Vulkan 1.4.354), 108 points, double
precision with `h = 1e-4`:

| Case | check | measured |
| --- | --- | --- |
| Minkowski | `max|Ric|`, `max|R|`, `max|G|` | exact zeros |
| Schwarzschild `M = 1` | `max|Ric|` | `1.83e-7` |
| Schwarzschild | Kretschmann vs `48M²/r⁶` | `1.11e-7` relative |
| Schwarzschild–de Sitter `Λ = 0.1` | `max|Ric − Λg|` | `6.94e-7` |
| Schwarzschild–de Sitter | `K` vs `48M²/r⁶ + 8Λ²/3` | `1.91e-7` relative |
| Kerr `a = 0.5` | vacuum `max|Ric|`, `max|G|` | `2.10e-7`, `1.42e-7` |
| Reissner–Nordström `Q = 0.5` | `max|G − 8πT|` | `1.09e-7` |
| FLRW `a = 1 + Ht + t²`, `k = 0.3` | `Ric`, `R`, `G` vs the closed forms | `1.27e-6` |
| Interior Schwarzschild `Rc = 5`, `Ra = 4` | `G` vs `8π diag(ρ,p,p,p)` | `8.90e-8` |

The Minkowski zeros are exact (a constant metric differentiates to zero). The
Schwarzschild residual is central-difference noise, not curvature: `|Ric|` is
four orders of magnitude below the curvature scale `M/r³ ≈ 0.04`. The de Sitter,
Kerr, charged, FLRW and interior-sphere cases are the controls — they have
genuinely nonzero curvature (or, for Kerr, non-diagonal components), recovered
to the same noise level, so the vacuum test is not vacuous.

The host also checks closed forms proved in Physlib: the Weyl electric part
against `diag(0, −2k, k, k)` at `k = M/r³` (`2.6e-9`, and `1.4e-8` with the
trace added back for `Λ = 0.1`), the four Schwarzschild–de Sitter Riemann
components, the frame Ricci tensor against `Λη`, and the Kerr and
Reissner–Nordström field equations. This is a numerical sanity check on the same
objects the Lean side defines; it is not a proof, and finite differences say
nothing about the analytic solution.

## Build and run

Lean (first build fetches Physlib at the pinned revision and its transitive Mathlib):

```sh
cd gravitation
lake exe cache get          # Mathlib oleans
lake build                  # kernel checks Gravitation and the Physlib modules
```

Vulkan:

```sh
cd gravitation/vulkan
make
./gr_vulkan shaders/tensor.comp.spv
```

Requires `glslc` (shaderc), `libvulkan`, an ICD and a device with
`shaderFloat64`; exits nonzero if a case exceeds tolerance. CI runs it on the
lavapipe software driver, so the check needs no GPU runner. `torchvulkan` is not
needed — the pipeline is a native compute shader with no PyTorch dependency.

## Axiom policy

The development may use only axioms that the base libraries already assume. In
practice that is `propext`, `Classical.choice` and `Quot.sound` — the three
axioms Mathlib and Physlib are built on. Neither this repository nor the audited
Physlib subtree declares an `axiom`, `constant` or `opaque`, and there is no
`sorry`, `admit`, `native_decide` or `Lean.trustCompiler`.

The check is automated over both surfaces — the local `Gravitation` module and
the vendored `PhyslibAlpha/Relativity/General/` tree:

```sh
scripts/audit_axioms.sh
```

It fails on any forbidden declaration, generates `#print axioms` for every
declaration (732 at this revision, 493 theorem-like) and rejects any axiom outside
`{propext, Classical.choice, Quot.sound}`. The audit runs in CI on every push and
pull request (`.github/workflows/axioms.yml`).

## Silent build

`lake build` prints no messages — no errors and no warnings. The rule is
enforced:

```sh
scripts/check_messages.sh
```

exits nonzero if the build emits anything, and CI runs it after `lake build`.

## Proof status

Every declaration is audited against the base axiom set. The per-declaration
table — name, file, axioms, status — lives in
[Proof-Status.md](Proof-Status.md); `scripts/proof_status.sh` generates it and
CI fails if it is out of date.
